# YOLOv8-based small object vehicle detection system based on deep learning (YOLOv8+)

## Body

Based on the YOLOv8 algorithm, this project has developed a computer vision system specifically for small object vehicle detection. It uses a custom dataset containing 5236 training images and 2245 validation images. The system focuses on the detection task of a single category ('car') and has significantly improved the model's recognition ability for small-sized vehicles through optimizing the network structure and training strategy of YOLOv8. This system can accurately detect various types of small vehicle targets in complex scenes, including distant vehicles, partially obscured vehicles, and vehicle targets in low-resolution environments. Experimental results show that the YOLOv8 model optimized for specific tasks achieves high accuracy and recall rates in the task of small object vehicle detection, verifying the effectiveness of this system in practical applications.
